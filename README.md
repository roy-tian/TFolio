# TFolio

TFolio is a PDF editor by Roy Tian, built with Rust, Tauri 2, React, and shadcn/ui.

## Development

```powershell
npm install
npm run tauri:dev
```

## Build the executable

```powershell
npm run tauri:build
```

The executable is written to `src-tauri/target/release/tfolio.exe` on Windows.

## Build installers

```powershell
npm run tauri:bundle
```

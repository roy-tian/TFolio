# TFolio

[English](README.md) · [简体中文](README_zh.md)

TFolio 是一款桌面 PDF 工作台（folio 原指书页）：阅读 PDF、添加批注、调整页面顺序、添加水印与页码，也可以把多个文件合并成一个。所有处理都在本机完成，TFolio 不会上传任何文档。

## 安装

在 [Releases 页面](https://github.com/roy-tian/TFolio/releases) 下载对应平台的安装包——macOS（Apple Silicon 与 Intel）、Windows x64、Linux x64。

## 功能

**阅读**

- 通过拖放、文件选择器或最近打开列表打开 PDF，多个文档可同时在标签页中打开。
- 将 TFolio 设为 PDF 的默认打开方式后，双击文件即可直接打开——若窗口已开着，就在其中新增一个标签页。
- 单页、书本（双页对开）与缩略图三种视图；支持缩放、适合宽度或适合页面、旋转。
- 页码指示与跳转输入框，以及由文档自身目录生成的书签侧栏。
- 直接在页面上选中并复制文字。

**页面**

- 在缩略图网格中拖动即可调整页面顺序。
- 删除页面、插入空白页，或新建一个空白 PDF。
- 把另一个 PDF 拖入文档，即可插入它的页面。

**批注**

- 高亮文字，绘制方框并应用半透明、马赛克或高斯模糊效果，添加可自定义颜色与字号的文字注释。
- 擦除任意一处标记，无论它位于编辑历史的哪一步。
- 全程支持撤销与重做，然后保存到原文件或导出副本。

**整篇文档**

- 覆盖每一页的文字水印——仅一份或平铺重复，两种对角方向，大小可调。
- 页面底部的页码：固定位置，或按双面装订左右镜像；可指定页码范围与起始编号，颜色在深色区域上自动转白，空白页如何计数也由你决定。
- 合并向导：按你排定的顺序合并多个 PDF，保留或重建它们的书签，可选择补足空白页使每个文件都从奇数页开始，并为合并结果添加页码和水印。

**应用本身**

- 简体中文与英文界面，优先采用你保存的偏好，其次跟随系统语言。
- 浅色与深色主题，默认跟随系统。
- 设置与最近打开列表在下次启动时保留。

## 须知

- 可打开不超过 512 MiB 的 PDF。
- 页面的解析与绘制由应用内置的 PDF 引擎完成，文档内容不会交给网页视图或服务器。TFolio 唯一一次访问网络，是在你同意下载中日韩字体时——仅当系统已装字体都无法绘制你输入的注释或水印文字。
- 水印、马赛克与模糊只是视觉效果，被遮盖的文字依然存在、依然可被搜索。它们不是脱敏手段，专业的 PDF 编辑器仍可将其还原。
- 一旦添加了水印、页码或其他文件的页面，该文档只能导出为副本，你打开的原文件不会被改动。
